# Карточка товара для Teaboom.ru

Тестовое задание: верхняя часть карточки «Ананасового улуна». HTML, SCSS и ванильный JS, без фреймворков.

**Демо:** https://liunamme.github.io/teaboom-product-card/

## Запуск

Собранный CSS лежит в `dist/`, поэтому достаточно поднять статический сервер в корне проекта:

```bash
npx serve . -l 5174
```

Открыть http://localhost:5174. Через `file://` JS не заработает: ES-модули браузер грузит только по http.

Работа со стилями:

```bash
npm install
npm run watch   # пересборка SCSS при сохранении
npm run build   # финальная сборка с autoprefixer
npm run lint    # stylelint, в том числе проверка БЭМ-имён
```

## Структура

Каждый компонент лежит в своей папке: Django-шаблон, стили и JS рядом. Подкомпоненты вложены в папку родителя. Имя папки совпадает с именем БЭМ-блока.

```
index.html                      демо-страница, собранная из тех же компонентов
src/
  main.scss                     точка входа стилей
  main.js                       точка входа JS
  styles/
    abstracts/                  токены, функции rem() и color(), миксины
    base/                       шрифты, CSS-переменные, страница, reduced motion
  lib/
    cart.js                     состояние корзины с подпиской на изменения
    format.js                   форматирование цены
    announcer.js                сообщения для скринридера
  components/
    product-card/               карточка целиком, собирает остальные компоненты
    product-gallery/            главное фото и миниатюры
      picture/                  адаптивное фото avif/webp/jpg
    lightbox/                   просмотр фото с листанием
    pack-picker/                выбор фасовки
      pack-option/              плитка одной фасовки
    price/                      цена, старая цена, выгода, цена за 100 г
    buy-box/                    кнопка «В корзину» и управление количеством
      qty/                      счётчик
    facts/                      плитки заваривания
    product-about/              блок «О чае»
    product-schema/             Schema.org для поисковиков
    breadcrumbs/                хлебные крошки с BreadcrumbList
    cart-fab/                   плавающая корзина
    btn/, icon-btn/             кнопки
    icons/                      SVG-спрайт
  pages/
    product.html                пример страницы на Django из компонентов
dist/css/main.css               собранные стили
assets/                         фото и шрифт Open Sans
```

Файлы стилей начинаются с `_`: это частичные файлы Sass, отдельно они не компилируются и подключаются только через `main.scss`.

## Как устроен JS

Каждый компонент это функция `initИмя(root)`: находит свои элементы, вешает обработчики и возвращает наружу только то, что нужно соседям, например `{ render }`. Компоненты не знают друг о друге, связывает их `initProductCard`: выбор фасовки приходит из `initPackPicker`, карточка передаёт её в `initPrice` и `initBuyBox`. Корзина в `lib/cart.js` общая, плавающая корзина подписана на её изменения. JS находит элементы по `data-*` атрибутам, поэтому классы можно менять, не трогая скрипты.

## Что сделано

**Стиль.** Цвета, шрифт и скругления сняты с teaboom.ru: жёлтый `#f5d730`, графит `#202020`, кремовый `#fefcef`, Open Sans, кнопки-«таблетки». Ховер у кнопок как на сайте: тёмный фон и жёлтый текст.

**Адаптив.** Mobile-first, брейкпоинты 768 и 1200. Раскладка карточки на `grid-template-areas`: HTML один, а блоки на каждом экране встают по-своему. Заголовок и цена масштабируются через `clamp()`.

- 375: фасовки лентой с прокруткой вбок, вместо цепочки крошек одна ссылка «назад».
- 768: фото слева, заголовок справа, покупка на всю ширину.
- 1440: две колонки, справа вся покупка.

**Фасовка.** Обычные `radio` внутри `fieldset`: выбор работает стрелками с клавиатуры и понятен скринридерам. Цены лежат в `data-*` у каждой фасовки. Если у фасовки нет `data-old-price`, старая цена, бейдж и «Выгода» скрываются. Проверить: удалить `data-old-price` у любой фасовки в `index.html`.

**Корзина.** Настоящей нет, количество хранится в памяти страницы. До добавления видна кнопка «В корзину», после него счётчик и «Оформить»: плюс и минус меняют количество в корзине, минус на единице убирает товар. У каждой фасовки своё количество, плавающая корзина показывает общее.

**Галерея.** Миниатюры под фото, клик по фото открывает просмотр на нативном `<dialog>`. Листается стрелками на экране и клавиатуре и свайпом, по кругу. Для демо во всех кадрах одно и то же фото с сайта.

**Семантика и SEO.** `article`, `nav` с `ol`, `h1`–`h3`, `fieldset`/`legend`, `dl` для характеристик, `data` для цены, `s` для старой цены. Schema.org в JSON-LD: `Product` с `Offer` на каждую фасовку и `BreadcrumbList`. Плюс `canonical`, `description`, Open Graph.

**Доступность.** Видимый фокус для клавиатуры, `aria-live` на цене, подписи у кнопок-иконок, фокус не теряется при смене кнопки на счётчик, области нажатия от 44px, `prefers-reduced-motion`.

**Скорость.** Главное фото в avif/webp/jpg с `srcset`, `fetchpriority="high"` и заданными размерами, страница не прыгает при загрузке. Шрифт свой, вариативный, разбит на кириллицу, латиницу и отдельный файл для знака ₽.

## Встраивание в Django

1. Добавить `src` в `TEMPLATES[0]["DIRS"]`, тогда компоненты подключаются как `{% include "components/product-card/product-card.html" %}`. Пример страницы: `src/pages/product.html`.
2. Стили и скрипты отдать через static: `dist/css/main.css` и `src/main.js` как `type="module"`.
3. `styles/base/_page.scss` на сайте не нужен, у `body` и контейнера там свои стили.
4. Глобальных сбросов нет, CSS-переменные с префиксом `--tb-`, существующие страницы не задеваются.

Какие данные ждут шаблоны:

| Поле | Что внутри |
|---|---|
| `product.name`, `product.lead`, `product.description` | название, короткое и полное описание |
| `product.category` | `name`, `get_absolute_url` |
| `product.images` | список кадров: `base` (путь без размера и расширения), `alt` |
| `product.packs` | фасовки по возрастанию веса: `sku`, `label`, `weight_g`, `price`, `old_price` или `None`, `saving`, `discount_percent`, `price_per_100g` |
| `product.facts` | параметры заваривания: `icon`, `label`, `value` |
| `product.taste_notes` | список строк |
| `product.specs` | характеристики: `icon`, `label`, `value` |
| `breadcrumbs` | разделы от корня: `name`, `url` |

Для каждого кадра рядом должны лежать файлы `base-480` и `base-970` в avif, webp и jpg, плюс `base-thumb.webp`.
