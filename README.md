# Карточка товара для Teaboom.ru

Тестовое задание: верхняя часть карточки «Ананасового улуна». HTML, SCSS и немного ванильного JS, без фреймворков.

**Демо:** https://liunamme.github.io/teaboom-product-card/

## Запуск

Собранный CSS уже лежит в `dist/`, поэтому достаточно поднять любой статический сервер в корне проекта:

```bash
npx serve . -l 5174
```

Открыть http://localhost:5174. Через `file://` не заработает JS: модули браузер грузит только по http.

Если нужно менять стили:

```bash
npm install
npm run watch   # пересборка SCSS при сохранении
npm run build   # финальная сборка с autoprefixer
npm run lint    # stylelint, заодно проверяет БЭМ-имена классов
```

## Как сделано

**Стиль.** Цвета, шрифт и скругления сняты с teaboom.ru: жёлтый `#f5d730`, графит `#202020`, кремовый `#fefcef`, Open Sans, кнопки-«таблетки». Ховер у кнопки «В корзину» как у кнопок на сайте: тёмный фон и жёлтый текст.

**Адаптив.** Mobile-first, брейкпоинты 768 и 1200. Раскладка карточки на `grid-template-areas`: HTML один, а блоки на каждом экране встают по-своему. Между брейкпоинтами вёрстка тоже не ломается, заголовок и цена масштабируются через `clamp()`.

- 375: фасовки лентой с прокруткой вбок, лента уходит за край карточки. Вместо длинных крошек одна ссылка «назад».
- 768: фото слева, заголовок справа, покупка на всю ширину строкой.
- 1440: две колонки, справа вся покупка.

**Фасовка.** Это обычные `radio` внутри `fieldset`, поэтому выбор работает стрелками с клавиатуры и понятен скринридерам. Данные о цене лежат в `data-*` у каждого radio, JS только читает их. Если у фасовки нет `data-old-price`, старая цена, бейдж скидки и «Выгода» скрываются сами. Проверить: удалить `data-old-price` у любой фасовки в `index.html`.

**Корзина.** Настоящей нет, по заданию, количество хранится в памяти страницы. Пока фасовки нет в корзине, видна кнопка «В корзину». После добавления вместо неё появляются счётчик и «Оформить»: плюс и минус меняют количество уже в корзине, а минус на единице убирает товар. У каждой фасовки своё количество, круглая корзина в углу показывает общее. Скринридер слышит каждое изменение, фокус не теряется, когда кнопка сменяется счётчиком.

**Доступность.** Видимый фокус для клавиатуры, `aria-live` на цене, подписи у кнопок-иконок, области нажатия от 44px, `prefers-reduced-motion`.

**Скорость.** Главное фото в avif/webp/jpg с `srcset`, `fetchpriority="high"` и заданными размерами, страница не прыгает при загрузке. Шрифт свой, вариативный, разбит на кириллицу, латиницу и отдельный файл для знака ₽.

**SEO.** Разметка Schema.org в JSON-LD: `Product` с `Offer` на каждую фасовку и `BreadcrumbList`. Плюс `canonical`, `description`, Open Graph.

## Как встроить в сайт

1. Шаблон `templates/product/_product_card.html` подключается через `{% include %}`. Какие данные он ждёт, описано в комментарии в начале файла.
2. Из SCSS не нужен `base/_page.scss`: это стили демо-страницы, на сайте у `body` и контейнера свои.
3. Все стили привязаны к своим классам, глобальных сбросов нет. CSS-переменные с префиксом `--tb-`, чтобы не пересечься с существующими.
4. JS подключается как модуль и находит карточку по `data-product`. Классы для него не важны, можно спокойно менять вёрстку.
